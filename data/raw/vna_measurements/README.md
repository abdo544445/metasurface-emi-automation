# VNA Measurement Raw Data Archive

This directory stores raw 2-port Vector Network Analyzer Touchstone (`.s2p`) measurement files acquired from WR-90 (X-band: 8.2–12.4 GHz) and WR-62 (Ku-band: 12.4–18.0 GHz) waveguide test fixtures.

### Expected File Naming Format:
* `golden_geom1_wr90_sample1.s2p`
* `golden_geom1_wr62_sample1.s2p`
* `golden_geom2_wr90_sample1.s2p`
* `golden_geom2_wr62_sample1.s2p`
